This file does NOT go on your web host.

chatbot-worker.js runs on Cloudflare Workers, a separate service from your
web hosting. It holds your Anthropic API key privately and powers the live
chat backend. This is already deployed and working at
eric-carr-chat.erccrr.workers.dev — this copy is a reference/backup in case
you need to redeploy or edit it later.

Don't include this folder when you upload the rest of this package to your
web server.
